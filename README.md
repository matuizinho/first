Descrição Geral

Um pequeno projeto para exercitar dinâmismo utilizando JavaScript.

Finalidade

A ideia do jogo é descobrir um número gerado aleatóriamente a partir de alguns critérios limitantes do mesmo, exercitando a lógica de intervalos fechados nessa geração de números randômicos aleatórios. 

Principais utilizações

Exercitar a utilização dos direcionamentos do HTML para o JS por meio do innerHTML e aprimorar a lógica de programação adequando a funcionalidade do jogo e contornando possíveis problemas durante o processo.
